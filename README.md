# Waters Roux Beta 27 actual application captures

Source: `79d5b77e167dcf2ff90aef8124b4a14521c72c61` on `feat/waters-roux-beta27`.
Captured November 10, 2026 from the actual Rust/wgpu viewer running on Linux
Xvfb with software Vulkan, using the existing offline demo/capture mode.
No grid login or personal credentials were used. These are not design mockups,
Windows taskbar proof, native file-picker proof, or human in-world acceptance.

The official downloadable logo PNG and standalone New Orleans background were
not available. Default screenshots deliberately show text identity and a
neutral gradient. The visual design is not approved. The amber perimeter and
decorative top strip are gone; warning and keyboard-focus colors remain.

`appearance-editor.png` shows the real Login Appearance / Branding window.
Its Login, Loading, Glass and Defaults tabs control independent settings.

`diagnostic-custom-images.png` is ONLY a rendering/persistence diagnostic:
synthetic checkered PNG fixtures were imported using the actual branding module,
saved to an isolated local test profile, their original files deleted, and the
viewer restarted. It demonstrates the selected background/logo and aligned
frosted card. The checkerboard is NOT an official logo, approved artwork,
proposed visual design, or the build's default. Loading choices were separately
imported and reloaded by the same smoke test; live teleport still needs a human.

`diagnostic-high-contrast.png` captures the same diagnostic profile in High
Contrast mode: the card becomes opaque black with readable white labels while
the background remains visible outside it. Human keyboard/assistive-technology
testing remains required.
