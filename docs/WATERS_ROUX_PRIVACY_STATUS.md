# Waters Roux Viewer — privacy documentation status (pre-release)

**This is an interim development notice, not a finalized privacy policy.** It does not replace the privacy, terms or data-use policies of Linden Lab or any other service you connect to.

The Waters Roux Beta 28 V3 developers must complete a source-level privacy and security audit **before** issuing a public v1.0.0 release. The audit must cover the viewer's local configuration and log paths, screenshots/recordings, crash diagnostics, community/news requests, network connections, update checks, and all credentials or third-party services. Users must review any diagnostics before choosing to post them publicly on GitHub.

## Public bug reports

Bug reports and feature requests are filed in the [Waters Roux GitHub Issues](https://github.com/WynnieOS/Waters-Roux-Viewer/issues). Issues and attachments posted to this repository may be visible to everyone. Never post account passwords, security tokens, private conversations, private locations, or unredacted logs.

## GitHub authorization

The previously embedded Aurora GitHub App client ID is not valid proof of a Waters Roux-owned authorization. **Direct in-viewer GitHub authorization and crash-report issue submission are disabled in Beta V3 source until a dedicated, approved Waters Roux GitHub App is configured and security-tested.** Browser-based reporting remains available; submitting a report requires a user action and GitHub sign-in.

## Publication gate

Before a public release, replace this interim notice with a reviewed, accurate Waters Roux privacy policy and verify the viewer's Preferences › Privacy link points to that policy. Do not present Aurora's privacy policy as Waters Roux's own policy or substitute unsupported privacy claims.
